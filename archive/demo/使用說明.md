# DEMO停車費計算系統使用說明

## 系統啟動

```bash
cd demo
python app.py
```

啟動後訪問：http://localhost:5001

## 功能介紹

### 1. 停車費計算器 (首頁)
- **網址**：http://localhost:5001/
- **功能**：計算停車費用
- **使用方式**：
  1. 選擇費率方案
  2. 輸入進場時間和出場時間
  3. 點擊"計算停車費"
  4. 查看計算結果和詳細明細

### 2. 費率編輯器
- **網址**：http://localhost:5001/rate_editor
- **功能**：管理費率方案
- **使用方式**：
  1. 選擇現有方案編輯或創建新方案
  2. 設定基本資訊（名稱、假日模式）
  3. 配置時段（名稱、開始時間、結束時間）
  4. 設定費率（費率、計費單位、上限）
  5. 測試方案正確性
  6. 儲存方案

## 預設方案

系統預設包含"萬華西園"方案：
- **日間時段**：07:00-18:00
  - 平日：30元/30分鐘，上限300元
  - 假日：40元/30分鐘，上限400元
- **夜間時段**：18:00-07:00
  - 平日/假日：10元/60分鐘，上限50元

## 測試案例

### 基本測試
- 進場：2025-06-20 10:00 (週五)
- 出場：2025-06-20 14:00 (週五)
- 預期結果：240元

### 跨日測試
- 進場：2025-06-20 20:00 (週五)
- 出場：2025-06-21 08:00 (週六)
- 預期結果：170元

### 多日測試
- 進場：2025-06-20 16:00 (週五)
- 出場：2025-06-23 09:00 (週一)
- 預期結果：1370元

## 核心特色

✅ **準確的跨日計算**：正確處理跨日停車的日期類別判斷
✅ **時段上限保護**：各時段獨立計算上限，避免超收
✅ **直觀的編輯界面**：可視化的費率方案編輯
✅ **即時測試功能**：內建測試確保方案正確性
✅ **詳細計費明細**：提供完整的費用分解說明

## 技術支援

如有問題，請檢查：
1. Python版本 (建議3.8+)
2. 依賴安裝：`pip install -r requirements.txt`
3. 端口占用：確保5001端口未被占用
