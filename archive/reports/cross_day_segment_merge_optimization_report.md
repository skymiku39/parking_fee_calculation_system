# 停車費計算系統 - 跨日時段合併優化報告

## 概述

本報告記錄了停車費計算系統中跨日時段處理邏輯的重大優化，解決了跨日時段被錯誤分割的問題，實現了用戶要求的"同一時段合併計算"功能。

## 問題背景

### 用戶反饋
用戶報告："這個時間的切法還是很奇怪，一定有問題，因為我採用的案例應當有一個10小時的夜間，但你的計算中看不到"

### 測試案例
- **進場時間**：2025-06-20 13:19
- **出場時間**：2025-06-21 23:19  
- **總停車時長**：2040分鐘 (34小時)
- **適用方案**：萬華西園 (日間08:00-22:00，夜間22:00-08:00)

### 原有問題
系統將跨日夜間時段錯誤地分成多個獨立明細：
- ❌ 06-20 夜間: 120分鐘 (22:00-24:00)
- ❌ 06-21 夜間前半: 480分鐘 (00:00-08:00) 
- ❌ 06-21 夜間後半: 79分鐘 (22:00-23:19)

用戶期望的"10小時夜間"（實際是11小時19分）被分割成3個明細，無法清楚看出跨日時段的整體性。

## 核心需求分析

### 用戶關鍵指導
"應該這樣處理，6/20後半夜應當與6/21前半夜的時間加再一起，再計算費率"

### 需求要點
1. **跨日時段合併**：同一個時段（如夜間22:00-08:00）的所有時間應該合併計算
2. **時間範圍顯示**：明細中要顯示實際的時間範圍，方便觀看
3. **計算邏輯統一**：合併後的時間作為一個整體進行費率計算

## 技術方案設計

### 架構重構：從分割到合併

**原有邏輯（錯誤）**：
```
按日期遍歷 → 每天計算時段重疊 → 生成多個分散明細
```

**新邏輯（正確）**：
```
計算每個時段的總時間 → 合併跨日實例 → 生成統一明細
```

### 核心函數重新設計

#### 1. `split_parking_time_by_segments()` 重構
- **改變**：從按日切割改為按時段合併
- **邏輯**：先計算每個時段在整個停車期間的總時間，然後生成合併明細

#### 2. 新增 `calculate_time_in_segment()`
- **功能**：計算停車時間在特定時段的總分鐘數
- **特點**：自動處理跨日時段的所有實例並合併

#### 3. 新增 `get_segment_time_range()`
- **功能**：生成時段的實際時間範圍顯示
- **格式**：`06-20 22:00-06-21 23:19` (跨日顯示)

#### 4. 新增 `is_cross_day_segment()`
- **功能**：判斷是否為跨日時段
- **邏輯**：結束時間 <= 開始時間

```python
    """計算停車時間在特定時段的總分鐘數（跨日時段會合併計算）"""
    
    if is_cross_day:
        # 跨日時段：計算所有重疊的時間段
        current_date = enter_time.date() - timedelta(days=1)
        end_date = exit_time.date() + timedelta(days=1)
        
        while current_date <= end_date:
            # 時段實例：從current_date的start_time到next_day的end_time
            instance_start = datetime.combine(current_date, segment_start_time)
            instance_end = datetime.combine(current_date + timedelta(days=1), segment_end_time)
            
            # 計算與停車時間的重疊並累加
            overlap_start = max(enter_time, instance_start)
            overlap_end = min(exit_time, instance_end)
            
            if overlap_start < overlap_end:
                total_minutes += int((overlap_end - overlap_start).total_seconds() / 60)
```

## 測試驗證

### 萬華西園方案測試結果

**修復前（錯誤）**：
```
06-20 夜間: 120分鐘 → 20元
06-21 夜間: 480分鐘 → 80元  
06-21 夜間: 79分鐘 → 20元
總計: 559分鐘分散在3個明細
```

**修復後（正確）**：
```
夜間 (06-20 22:00-06-21 23:19): 679分鐘 (11小時19分) → 120元
總計: 679分鐘合併為1個明細
```

### 詳細時間驗證

1. **夜間實例1**：06-20 22:00 - 06-21 08:00 = 600分鐘 (10小時)
2. **夜間實例2**：06-21 22:00 - 06-21 23:19 = 79分鐘 (1小時19分)
3. **夜間總計**：600 + 79 = 679分鐘 (11小時19分)

### 費用計算驗證

- **夜間費用**：679分鐘 ÷ 60分鐘 = 11.32 → 12單位 × 10元 = 120元
- **總費用**：1380 + 120 = 1500元 ✅
