## 🐛 發現的問題

### 問題描述
在設定頁面的費率方案配置中，存在邏輯矛盾的選項：

1. **適用日期類型** - 包含選項 "全部日期"
2. **是否適用於假日** - 包含選項 "是" 或 "否"

### 問題分析
當用戶選擇 "全部日期" 時，再詢問 "是否適用於假日" 是沒有意義的，因為：
- "全部日期" 本身就包含了假日
- 這造成了邏輯上的混淆和冗餘

## 🔧 修正方案

### 1. 動態顯示控制
實施智能的選項顯示邏輯：

```javascript
function toggleHolidayOption() {
  const dateType = document.getElementById('dateType').value;
  const holidayGroup = document.getElementById('holidayOptionGroup');
  
  if (dateType === 'all' || dateType === 'holiday') {
    // 選擇"全部日期"或"假日"時，隱藏假日選項
    holidayGroup.style.display = 'none';
    document.getElementById('applyOnHoliday').value = 
      dateType === 'all' ? 'true' : 'false';
  } else {
    // 選擇"平日"或"週末"時，顯示假日選項
    holidayGroup.style.display = 'block';
  }
}
```

### 2. 用戶提示改善
在假日選項下方添加說明文字：
```html
<small style="color: #666; margin-top: 5px; display: block;">
  此選項僅在選擇"平日"或"週末"時有效
</small>
```

### 3. 顯示邏輯優化
改善方案標籤的顯示邏輯：
- 平日 + 適用假日 → 顯示為 "平日+假日"
- 週末 + 適用假日 → 顯示為 "週末+假日"
- 全部日期 → 直接顯示 "全部日期"
- 假日 → 直接顯示 "假日"
