# 設定檔說明

本目錄存放系統執行期的 JSON 設定檔。

| 檔案 | 用途 |
|------|------|
| `system_config.json` | 全域系統參數（UI 設定、假日 API 等） |
| `system_calendar.json` | 自訂假日日曆 |
| `system_templates.json` | 多維度範本的維度定義 |
| `multidimensional_rate_plans.json` | 多維度費率範本（精選方案來源） |
| `user_defined_plans.json` | 使用者自行建立的費率方案 |
| `rate_plans.json` | 傳統費率方案定義 |
| `universal_rate_plans.json` | 萬用計算器方案定義 |
