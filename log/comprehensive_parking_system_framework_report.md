## 📊 系統架構與實現

### 1. 核心配置框架

#### 1.1 停車場基本資訊配置
```json
{
  "parking_lot_info": {
    "lot_name": "停車場名稱",
    "lot_type": "停車場類型",
    "operating_hours": "營業時間",
    "min_billing_unit": "最小計費單位(分鐘)",
    "grace_period_minutes": "寬限期(分鐘)"
  }
}
```

#### 1.2 計費模式分類

| 模式名稱 | 模式ID | 適用場景 | 實現狀態 |
|---------|-------|----------|----------|
| 全天統一費率 | `unified_flat_rate` | 簡單停車場 | ✅ |
| 日間夜間費率 | `day_night_rates` | 區分時段的停車場 | ✅ |
| 多段式費率 | `multi_segment_rates` | 複雜商業區域 | ✅ |
| 平日假日費率 | `weekday_holiday_rates` | 一般停車場 | ✅ |
| 平日假日節慶費率 | `weekday_holiday_festival_rates` | 商業中心 | ✅ |
| 計次收費 | `per_entry_rate` | 機車停車場 | ✅ |

### 2. 車輛類型支援

系統現在支援以下車輛類型的差異化費率設定：

- **汽車 (Car)**: 基準費率倍數 1.0
- **機車 (Motorcycle)**: 基準費率倍數 0.4
- **大型車 (Large Vehicle)**: 基準費率倍數 1.8
- **電動車 (Electric Vehicle)**: 基準費率倍數 0.7 (環保優惠)
- **自行車 (Bicycle)**: 基準費率倍數 0.1

### 3. 優惠機制實現

#### 3.1 優惠類型

| 優惠類型 | 計算方式 | 應用場景 | 疊加規則 |
|---------|---------|----------|----------|
| 百分比折扣 | `percentage` | 里民優惠、信用卡優惠 | 可疊加 |
| 固定金額減免 | `fixed_amount` | 會員優惠、特殊活動 | 可疊加 |
| 免費時數 | `free_hours` | 身心障礙優惠、消費折抵 | 可疊加 |

#### 3.2 優惠疊加邏輯

- **疊加模式**: 加法疊加但有上限
- **最大折扣百分比**: 50%
- **最大折扣金額**: 200元
- **優先級系統**: 身心障礙優惠 > 會員優惠 > 里民優惠 > 消費折抵 > 信用卡優惠

### 4. 動態定價功能

#### 4.1 佔用率調整
- 90%以上佔用率：加收10%
- 50%以下佔用率：減收5%

#### 4.2 事件調整
- 演唱會：1.5倍費率
- 國定假日：1.3倍費率
- 節慶活動：1.4倍費率

#### 4.3 天氣調整
- 雨天：1.1倍費率
- 颱風天：0.8倍費率
