## 技術實現細節

### 自訂方案數據流
```
用戶建立方案 → 儲存到 user_defined_plans.json
↓
系統載入方案列表 → 包含自訂方案
↓
用戶選擇自訂方案 → 系統檢測方案類型
↓
呼叫自訂計算引擎 → 執行計算邏輯
↓
返回標準化結果 → 前端顯示結果
```

### 計算引擎架構
```
SmartParkingSystem.calculate_parking_fee()
├── is_user_defined_plan() → 檢測方案類型
├── calculate_with_user_defined_plan() → 自訂方案計算
├── calculate_with_multidimensional() → 多維度計算
└── calculate_with_traditional() → 傳統計算
```

### 核心算法
```python
# 時間區段計算
def calculate_time_in_segment(enter_time, exit_time, segment):
    # 計算時間重疊
    actual_start = max(enter_time, segment_start)
    actual_end = min(exit_time, segment_end)
    return max(0, actual_end - actual_start)

# 費用計算
def calculate_segment_fee(minutes, rate_config):
```
