# 跨日和跨時段計算修復報告

## 問題描述
用戶反映系統存在兩個關鍵問題：
1. 時間區段設定沒辦法自由設定時間
2. 跨日費用或跨時段費用計算有問題

## 問題分析

### 問題1：時間區段設定限制
在 `templates/rate_plan_designer.html` 中發現：
- 二段和三段模式的時間區段被設定為 `readonly`
- 用戶無法修改預設的時間設定
- 影響用戶自訂方案的靈活性

### 問題2：跨日計算邏輯錯誤
在 `app.py` 的 `calculate_time_in_segment()` 函數中發現：
- 原始代碼包含註釋「簡化處理：假設時段在同一天內」
- 完全沒有處理跨日時段的計算邏輯
- 對於18:00-07:00這樣的夜間時段計算完全錯誤

## 修復方案

### 修復1：開放時間區段設定
**修改文件**：`templates/rate_plan_designer.html`

**原始代碼**：
```javascript
addSegmentToContainer("日間", "07:00", "18:00", true);  // locked=true
addSegmentToContainer("夜間", "18:00", "07:00", true);  // locked=true
```

**修復後**：
```javascript
addSegmentToContainer("日間", "07:00", "18:00", false); // locked=false
addSegmentToContainer("夜間", "18:00", "07:00", false); // locked=false
```

**效果**：
- 用戶可以自由調整二段和三段模式的時間
- 增加界面提示「（可調整時間）」
- 保持全天模式的鎖定狀態（因為不需要調整）

### 修復2：重寫跨日計算邏輯
**修改文件**：`app.py`

**核心改進**：
1. **跨日判斷**：`is_cross_day = segment_end_time <= segment_start_time`
2. **多日處理**：支援停車時間跨越多天的情況
3. **精確重疊計算**：正確計算時段與停車時間的重疊部分

**新算法流程**：
```python
def calculate_time_in_segment(enter_time, exit_time, segment):
    # 1. 判斷是否為跨日時段
    is_cross_day = segment_end_time <= segment_start_time
    
    # 2. 遍歷每一天
    current_date = enter_time.date()
    while current_date <= exit_time.date():
        # 3. 構建當天的時段時間
        segment_start = datetime.combine(current_date, segment_start_time)
        if is_cross_day:
            segment_end = datetime.combine(current_date + 1天, segment_end_time)
        else:
            segment_end = datetime.combine(current_date, segment_end_time)
        
        # 4. 計算重疊時間
        overlap_start = max(enter_time, segment_start)
        overlap_end = min(exit_time, segment_end)
        
        if overlap_start < overlap_end:
            total_overlap_minutes += 重疊分鐘數
        
        # 5. 移到下一天
        current_date += 1天
```
