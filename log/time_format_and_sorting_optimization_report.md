# 時間格式和排序優化報告

## 背景
用戶反饋停車費計算系統中存在兩個顯示問題：
1. 時間範圍顯示不統一，缺少括號
2. 排序邏輯需要調整，同一天的日間時段應排在夜間時段前面

## 問題分析

### 1. 時間格式顯示問題
**用戶需求**：
- 時間範圍統一加括號：`06-21 日間 08:00-22:00` → `06-21 日間 (08:00-22:00)`
- 時長顯示的括號：只有換算小時才需要括號
  - `458分鐘 (7小時38分)` → 保持不變
  - `15分鐘` → 保持不變

**問題原因**：
- 時間範圍顯示邏輯中缺少括號包裝
- 時長格式化邏輯正確，無需修改

### 2. 排序問題
**用戶期望排序**：
- 06-20 日間 (14:22-22:00)
- 06-20~06-21 夜間 (22:00-08:00)
- 06-21 日間 (08:00-22:00)
- 06-21~06-22 夜間 (22:00-08:00)
- 06-22 日間 (08:00-22:00)
- 06-22 夜間 (22:00-23:22)

**問題分析**：
同一天的日間時段應該排在夜間時段前面，需要調整排序優先級。

## 技術修復

### 1. 時間範圍顯示修復
**修改位置**：`app.py` 第1082行

**修改前**：
```python
time_range_display = (
    f"{date_str} {segment_name} {interval['time_range']}"
)
```

**修改後**：
```python
time_range_display = (
    f"{date_str} {segment_name} ({interval['time_range']})"
)
```

### 2. 排序邏輯優化
**修改位置**：`app.py` 第1095-1102行

**實現邏輯**：
```python
def sort_key(detail):
    date = detail["date"]
    segment = detail["segment"]
    time_range = detail.get("time_range", "")
    
    # 定義時段優先級：日間 > 夜間
    segment_priority = 0 if "日間" in segment else 1
    
    return (date, segment_priority, time_range)
```

**排序規則**：
1. 首先按日期排序
2. 同一天內，日間時段優先級為0，夜間時段優先級為1
3. 最後按時間範圍排序
