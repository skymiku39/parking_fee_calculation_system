# 方案分組與說明

本文件整理目前系統中的「用戶自訂方案」與「內建精選模板」，說明分組邏輯、推薦方案與使用情境。

## 分組維度

- 時段類型（segment_type）
  - 全天：單一 00:00-24:00
  - 二段：日間/夜間分段
  - 多時段：三段或以上（含自訂）
- 假日類型（holiday_type）
  - 無假日：平日與假日同價
  - 平日假日：平日與假日分價
  - 國定假：國定假日另有費率（見多維度模板）
- 價格模型
  - 單一：單一單位價
  - 累進：隨時長進入不同區段的累進費率
- 上限類型
  - 日上限：當日最高收費
  - 分段上限：單一時段內的最高收費
- 全局寬裕時間（global_grace_time）

## 內建精選模板（固定顯示）

- 全天統一：`全天_無假日費率`
- 兩段週末：`兩段_六日費率`
- 四段國定：`四段_國定假費率`

說明：內建模板定義於 `config/multidimensional_rate_plans.json`，UI 只曝光以上三個精選選項，其餘模板保留供擴充。

## 推薦用戶自訂方案（featured）

- 跨日測試方案（二段／無假日／單一／無日上限／無分段上限／全局寬裕 15 分）
  - 優點：簡潔且可驗證跨日計費邏輯
  - 適用：一般場景驗證、開發測試
- 萬華西園（二段／平日假日／單一／分段上限／無全局寬裕）
  - 優點：具代表性的實務參數（夜間分段上限）
  - 適用：跨日＋假日差別之實務情境

要標記方案為精選，可在 `config/user_defined_plans.json` 的該方案加入：

- `"featured": true` 或 `"tags": ["featured"]`

## 方案分組總覽（用戶自訂）

- 全天（無假日）
  - 全天無上限（單一／無日上限／無分段上限／全局寬裕 15）
  - 全天有上限（單一／日上限／無分段上限／全局寬裕 15）
  - 全天累進費率無上限（累進／無日上限／無分段上限／全局寬裕 15）

- 二段（無假日）
  - 兩段無上限（單一／無日上限／無分段上限／全局寬裕 15）
  - 兩段有上限（單一／日上限／無分段上限／全局寬裕 15）
  - 兩段有分段上限（單一／無日上限／分段上限／全局寬裕 15）
  - 跨日測試方案（單一／無日上限／無分段上限／全局寬裕 15）
  - 測試方案2（單一／無日上限／無分段上限／全局寬裕 15）
  - 全局寬裕時間測試（單一／無日上限／無分段上限／全局寬裕 20）

- 二段（平日假日）
  - 萬華西園（單一／無日上限／分段上限／無全局寬裕）

- 多時段（平日假日）
  - 計費週期測試方案（單一／無日上限／無分段上限／無全局寬裕）

完整屬性表請參見 `tools/plan_catalog.md`。

## UI 顯示控制

- 內建精選固定三個（全天/兩段/四段）。
- 用戶自訂方案顯示數量可在 `config/system_config.json` 中調整：
  - `ui_settings.max_user_plans_display`（預設 5）
  - `ui_settings.show_only_featured_user_plans`（只顯示 featured）

## 使用建議

- 需要極簡清單：標記 2-3 個常用自訂方案為 featured，並將 `show_only_featured_user_plans` 設為 true。
- 驗證跨日與假日差別：使用「跨日測試方案」與「萬華西園」。
- 測試累進與上限：使用「全天累進費率無上限」「兩段有上限」「兩段有分段上限」。
